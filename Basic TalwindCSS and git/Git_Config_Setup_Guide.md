# Git Config Setup (VS Code)

## 1. VS Code Terminal খুলুন

-   \`Ctrl + \`\`
-   অথবা **Terminal → New Terminal**

## 2. আপনার GitHub নাম এবং ইমেইল সেট করুন

``` bash
git config --global user.name "আপনার নাম"
git config --global user.email "আপনার-ইমেইল@example.com"
```

উদাহরণ:

``` bash
git config --global user.name "Apurba Roy"
git config --global user.email "apurba@example.com"
```

## 3. সেট হয়েছে কিনা যাচাই করুন

``` bash
git config --global user.name
git config --global user.email
```

## 4. GitHub-এর কোন ইমেইল ব্যবহার করবেন?

GitHub → **Settings → Emails** এ গিয়ে **Primary email** ব্যবহার করুন।
